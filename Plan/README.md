## Contests — the short answer (full reasoning in `09_Contest_Strategy.md`)

| | |
|---|---|
| Daily **full** virtual contest (90 min) | ❌ **No.** It multiplies intake and starves consolidation — exactly the failure mode that produced 650 problems at 60% cold-solve. |
| Daily **micro-contest** (45 min, 2 unseen problems, hidden tags, timed, out loud) | ✅ **Yes, every weekday.** ~90% of the benefit at ~35% of the cost. |
| Live rated contest | ✅ **1/week minimum** — LC Weekly (Sun 08:00 IST) + Biweekly (alt Sat 20:00 IST) |
| Virtual contest | ✅ **1/week from Week 7** — and only if last week's upsolve is finished |
| 🔒 The iron rule | **Never enter a contest you don't have time to upsolve.** The upsolve *is* the training. |
